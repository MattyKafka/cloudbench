# CloudBench v3 — lokální spuštění

1. Rozbal složku `cloudbench`.
2. Otevři ji ve VS Code.
3. V souboru `index.html` použij **Open with Live Server**.
4. Zkontroluj přehled, všechny tři testovací stránky a měření přenosu.

Projekt je čisté HTML, CSS a JavaScript; Python ani Node.js nejsou nutné.

**Poznámka k metodice:** Výsledky jsou ovlivněny připojením, cache prohlížeče a CDN.
Veřejné URL zatím nejsou vyplněny. Doplní se po nasazení do `data/platforms.json`.
